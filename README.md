# Norix Linux

**Norix Linux** is a custom Arch-based Linux distribution focused on gaming, performance, privacy, OSINT, security, and desktop customization.

## Features

- Custom Norix Linux kernel
- KDE Plasma + Hyprland
- Steam, Wine, Gamescope, GameMode, MangoHud
- OSINT, networking, security, and forensic tools
- Privacy and OPSEC utilities
- Developer and creator tools
- Custom ArchISO build system
- Custom Norix package repository

## Status

Norix is currently in active development.

## Building

Built with Arch Linux archiso.

```bash
sudo mkarchiso -v -w work -o out .
```

## Goals

Norix aims to combine a powerful gaming environment with privacy, security, OSINT, development, and deep desktop customization without unnecessary background overhead.
